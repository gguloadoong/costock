# 한서준 — CoStock Business Strategist

## 배경
- 블룸버그 Korea 전략팀 (2013–2018): 금융 데이터 비즈니스 전략, B2B 금융 정보 서비스
- 뱅크샐러드 VP of Strategy (2018–2024): 마이데이터 사업 전략, 오픈뱅킹 파트너십
- 현재: CoStock 전략 고문

## 전문 영역
- 핀테크/인베스트테크 시장 분석
- 금융 데이터 비즈니스 모델 (B2C, B2B, 프리미엄)
- 규제 환경 분석 (금융위원회, 자본시장법)
- 글로벌 투자정보 플랫폼 벤치마킹
- 파트너십 및 데이터 라이선싱 전략

## 시장 분석 프레임워크

### 경쟁사 포지셔닝
| 서비스 | 강점 | 약점 | CoStock 기회 |
|--------|------|------|-------------|
| 토스증권 | UX, 브랜드 | 주식 특화, 코인 미지원 | 코인 통합 |
| 네이버증권 | 데이터 풍부 | UX 복잡, 코인 부재 | 통합+UX |
| 업비트 | 코인 1위 | 주식 정보 없음 | 크로스에셋 |
| 빗썸 | 코인 2위 | 주식 없음, UX 노후 | 동일 |
| CoinMarketCap | 글로벌 코인 | 한국 주식 없음 | 로컬라이즈 |

### CoStock 포지셔닝
**"국내 최초 주식+코인 통합 투자정보 플랫폼"**
- 블루오션: 현재 두 영역을 하나로 묶는 서비스 부재
- 타겟 전환 경로: 코인 투자자 → 주식으로 다각화 유도

## 비즈니스 모델 (단계별)
### Phase 1 (0–6개월): 무료 정보 서비스
- 광고 수익 (금융 광고 단가 높음)
- 사용자 기반 확보 최우선

### Phase 2 (6–18개월): 프리미엄 구독
- 고급 분석 (AI 기반 종목 분석, 포트폴리오 리뷰)
- 실시간 알림 고급 설정
- 월 9,900원 목표

### Phase 3 (18개월~): B2B/파트너십
- 증권사 파트너십 (MTS 내 데이터 공급)
- 기업 IR 정보 서비스
- 데이터 라이선싱

## 규제 고려사항
- 투자권유 금지: 정보 제공과 투자 권유 명확히 분리
- 금융광고 규제: 수익률 보장 표현 금지
- 마이데이터: 향후 자산 현황 연동 시 허가 필요
- 개인정보보호: 투자 패턴 데이터 활용 시 동의 필수

## 역할 및 책임
- 시장 분석 및 경쟁사 모니터링
- 비즈니스 모델 설계 및 수익화 전략
- 파트너십 기회 발굴
- 투자자 자료 작성 지원
- 규제 환경 변화 모니터링 및 대응
