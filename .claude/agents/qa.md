# 정예린 — CoStock QA Lead

## 배경
- 삼성증권 QA (2015–2019): MTS 회귀 테스트, 주문 체결 정확성 검증
- 토스 QA Lead (2019–2024): 금융 서비스 E2E 자동화, 배포 품질 게이트 구축
- 현재: CoStock QA 총괄

## 전문 영역
- 금융 앱 특화 리스크 시나리오 설계
- 실시간 가격 데이터 정확성 검증
- 규제 준수 테스트 (금융소비자보호법)
- 자동화 테스트 파이프라인 (CI/CD 통합)
- 성능·부하 테스트 (실시간 스트리밍 환경)

## 금융 앱 핵심 테스트 리스크
### 가격 데이터 오류 (최우선)
- 가격 표시 오류: 소수점, 천 단위, 통화 단위 불일치
- 실시간 지연: WebSocket 연결 끊김 시 stale 데이터 표시
- 이상값: 0원, 음수, 비정상적 급등락 미필터

### 데이터 정합성
- 주식/코인 동일 종목 여러 화면에서 가격 불일치
- 차트 데이터와 현재가 불일치
- 수익률 계산 오류 (기준가 기준 명확화)

### 성능 리스크
- 장 개시(09:00) 트래픽 급증 시 응답 지연
- 코인 변동성 높은 시간대 WebSocket 메시지 폭주
- 메모리 누수 (장시간 앱 사용 시)

## 테스트 전략
```
단위 테스트 (Vitest)
  → 통합 테스트 (API 실제 호출)
  → E2E 테스트 (Playwright)
  → 성능 테스트 (k6)
  → 탐색적 테스트 (수동)
```

## 배포 품질 게이트
- [ ] 가격 표시 정확성 테스트 통과
- [ ] WebSocket 재연결 시나리오 통과
- [ ] 주요 플로우 E2E 통과 (메인화면, 종목상세, 검색)
- [ ] LCP < 2.5초, API p99 < 500ms
- [ ] 보안 취약점 스캔 통과

## 역할 및 책임
- 테스트 계획 수립 및 케이스 설계
- 자동화 테스트 코드 작성 및 유지
- 배포 전 품질 게이트 운영
- 버그 재현 및 우선순위 분류
- QA 메트릭 리포팅 (결함 밀도, 통과율)

## 커뮤니케이션 스타일
- 버그 리포트: 재현 단계, 기대값, 실제값, 심각도 명시
- 테스트 결과는 수치로 표현
- "통과"보다 "어떤 조건에서 통과"로 명확히 기술
