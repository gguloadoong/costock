# CoStock 반복 작업 실행

CoStock 팀의 반복 작업을 주기적으로 실행합니다.

## 사용법

```
/loop [간격] [커맨드]
```

### 예시
```
/loop 10m /standup        # 10분마다 스탠드업 체크
/loop 30m /team-meeting   # 30분마다 팀 회의 상태 확인
/loop 5m check-prices     # 5분마다 가격 데이터 이상 감지
```

---

## CoStock 정기 반복 작업

### 실시간 모니터링 (운영 중)

#### 가격 데이터 무결성 체크 (`/loop 1m price-check`)
최재원이 담당하는 실시간 데이터 파이프라인 헬스 체크:
- WebSocket 연결 상태 확인
- 가격 이상값 감지 (0원, 음수, ±30% 급변)
- stale 데이터 여부 (마지막 업데이트 30초 초과)
- Kafka consumer lag 모니터링

#### API 가용성 체크 (`/loop 5m api-health`)
- 업비트 API 응답 시간 < 200ms
- KRX 오픈API 상태
- 한국투자증권 API 상태
- 자체 REST API 에러율 < 0.1%

### 개발 워크플로우

#### 스탠드업 리마인더 (`/loop 24h /standup`)
- 매일 오전 10시 스탠드업 시작
- 15분 후 자동 마감 알림

#### 백로그 리뷰 (`/loop 7d backlog-review`)
정예린 + 이준혁이 매주 금요일:
- P0/P1 미완료 항목 확인
- 새로운 버그 리포트 우선순위 배정
- 다음 스프린트 씨앗 아이템 정리

## 루프 관리

### 활성 루프 확인
현재 실행 중인 루프 목록을 보려면:
```
/loop list
```

### 루프 중단
특정 루프를 중단하려면:
```
/loop stop [루프 ID]
```

### 루프 일시 중지
```
/loop pause [루프 ID]
```

---

## 주의 사항
- 금융 데이터 모니터링 루프는 거래 시간(09:00~15:30)에만 실행 권장
- 코인 모니터링은 24/7 실행 (업비트 API 무중단)
- 루프 실패 시 최재원에게 즉시 알림
- API 호출 루프는 레이트 리밋 고려 (업비트: 초당 10회 제한)
