# CoStock 새 에이전트 추가

CoStock 팀에 새로운 전문가 에이전트를 추가합니다.

## 사용법

이 커맨드를 실행하면 아래 인터뷰 프로세스를 통해 새 에이전트 파일을 생성합니다.

---

## 에이전트 생성 인터뷰

다음 질문에 답해주세요:

### 기본 정보
1. **이름**: 이 에이전트의 이름은 무엇인가요? (예: 이민수)
2. **역할**: 어떤 역할을 담당하나요? (예: Data Engineer, DevOps, Security)
3. **에이전트 ID**: 커맨드에서 사용할 ID는? (예: `data-engineer`, `devops`, `security`)

### 배경 및 전문성
4. **경력**: 어떤 회사/팀에서 어떤 경험을 했나요?
   - 예: "두나무 데이터팀 → 카카오 데이터플랫폼 → 현재"
5. **핵심 전문 분야**: 이 에이전트가 가장 잘 아는 것은?
6. **도메인 지식**: CoStock 관련 특화 지식이 있다면?

### 행동 방식
7. **커뮤니케이션 스타일**: 어떻게 말하나요? (예: 데이터 기반 직설적, 꼼꼼한 문서화 중시)
8. **의사결정 방식**: 어떤 기준으로 판단하나요?
9. **협업 스타일**: 팀과 어떻게 일하나요?

---

## 에이전트 파일 템플릿

인터뷰 답변을 바탕으로 `.claude/agents/[id].md` 파일을 생성합니다:

```markdown
---
name: [이름]
description: [역할 한 줄 설명. 언제 이 에이전트를 사용하는지 명시]
---

# [이름] — [직책]

## 배경
[경력 및 전문성 서술]

## 전문 분야
[핵심 기술 스택 및 도메인 지식]

## CoStock 역할
[이 프로젝트에서 담당하는 구체적인 업무]

## 커뮤니케이션 스타일
[말투, 접근 방식, 팀 내 역할]

## 의사결정 기준
[무엇을 중요하게 여기는지]

## 도메인 지식
[CoStock 특화 지식 — 금융, 데이터, 보안 등]
```

## 현재 팀 구성

| 에이전트 ID | 이름 | 역할 |
|-------------|------|------|
| `pm` | 이준혁 | PM |
| `designer` | 박소연 | Designer |

| `be` | 최재원 | Backend |

## 추가 후 할 일

1. `.claude/agents/[id].md` 생성 확인
2. `CLAUDE.md` 팀 구성 표에 추가
3. 관련 커맨드 파일에 새 에이전트 참석자로 추가 (필요 시)
4. 팀원들에게 새 에이전트 소개 (`/team-meeting` 안건 추가)
