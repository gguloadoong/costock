# CoStock 팀 주간 회의

CoStock 팀 주간 전체 회의를 진행합니다.

## 참석자
- 이준혁 (PM) — 진행
- 박소연 (Designer)
- 김민준 (FE)
- 최재원 (BE)
- 정예린 (QA)
- 한서준 (Strategist)

## 아젠다 (60분)

### 1. 지난 주 회고 (10분)
각 팀원이 한 주 성과를 간략히 공유:
- 완료한 작업
- 블로커가 됐던 이슈
- 다음 주로 넘어가는 항목

### 2. 주요 지표 리뷰 (10분) — 이준혁
- DAU, 세션 수, 체류 시간
- 가격 데이터 지연 현황
- API 에러율, 가용성

### 3. 현재 스프린트 진행 상황 (15분)
- 백로그 현황 점검 (`.project/backlog.md`)
- 각 담당자 진행률 공유
- 블로커 해결 방안 논의

### 4. 기술/디자인 이슈 논의 (15분)
- 최재원: 실시간 데이터 파이프라인 이슈
- 김민준: FE 구현 이슈 및 성능 현황
- 박소연: 디자인 변경/업데이트 사항
- 정예린: 발견된 버그 및 품질 이슈

### 5. 전략 업데이트 (5분) — 한서준
- 경쟁사 동향
- 시장 변화 사항

### 6. 다음 주 계획 (5분) — 이준혁
- 스프린트 목표 재확인
- 우선순위 조정 필요 사항

## 회의 규칙
- 15분 초과 시 별도 미팅으로 분리
- 결정 사항은 즉시 `.project/decisions.md`에 ADR 추가
- 회의록은 `.project/meeting-notes/YYYY-MM-DD.md`로 저장
