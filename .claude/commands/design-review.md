# CoStock 디자인 리뷰 세션

CoStock 팀 디자인 리뷰를 진행합니다.

## 참석자
- 박소연 (Designer) — 발표
- 이준혁 (PM) — 제품 관점 피드백
- 김민준 (FE) — 구현 가능성 검토
- 최재원 (BE) — 데이터 제공 가능성 검토
- 정예린 (QA) — 테스트 가능성 검토
- 한서준 (Strategist) — 비즈니스/경쟁사 관점

## 리뷰 아젠다 (60분)

### 1. 리뷰 범위 공유 (박소연, 5분)
- 이번 리뷰 대상 화면/컴포넌트 소개
- 디자인 결정 배경 설명
- 특별히 피드백받고 싶은 포인트 명시

### 2. 금융 UX 관행 체크 (박소연 + 이준혁, 10분)
- 상승 빨강(`#E84040`) / 하락 파랑(`#2563EB`) 적용 여부
- 가격 숫자 포맷 (천 단위 콤마, 소수점 2자리)
- 변동률 부호 표시 (`+2.34%` / `-1.56%`)
- stale 데이터 표시 방식 (실시간 연결 끊김 상태)

### 3. 사용성 검토 (전체, 15분)
- **이준혁**: 사용자 플로우가 PRD 요구사항과 일치하는가?
- **한서준**: 경쟁사(토스증권, 업비트) 대비 차별화 요소가 보이는가?
- 타겟 사용자 (20대 코인 투자자 / 4050 주식 투자자) 관점 검토

### 4. 구현 타당성 검토 (김민준 + 최재원, 15분)
- **김민준**: 컴포넌트 구현 난이도 및 디자인 시스템 재사용성
- **최재원**: 필요한 API 데이터 제공 가능 여부
- 애니메이션/인터랙션 구현 가능 여부
- 성능 영향 (실시간 업데이트 시 리렌더링 최소화)

### 5. QA 관점 검토 (정예린, 10분)
- 엣지 케이스 UI 처리 (데이터 없음, 로딩, 에러 상태)
- 접근성 고려 (색맹 사용자 — 상승/하락 색상 보조 지표 필요)
- 모바일/태블릿 반응형 확인 포인트

### 6. 피드백 정리 및 수정 방향 합의 (박소연 + 이준혁, 5분)
- 반드시 수정 (Blocker)
- 권고 수정 (Should)
- 선택 수정 (Nice to have)
