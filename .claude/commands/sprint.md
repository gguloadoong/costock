## 스프린트 계획 (Planning, 90분)

### 1. 스프린트 목표 설정 (이준혁, 15분)
- 이번 스프린트에서 달성할 비즈니스 목표
- 전 스프린트 미완료 항목 이월 여부 결정
- 성공 기준(Definition of Done) 명시

### 2. 백로그 검토 및 우선순위 (이준혁 + 한서준, 20분)
- `.project/backlog.md` 열어서 P0/P1 항목 리뷰
- 투자자/사용자 피드백 반영 우선순위 조정
- 기술 부채 항목 포함 여부 결정

### 3. 기술 이슈 사전 파악 (최재원 + 김민준, 20분)
- 실시간 데이터 파이프라인 관련 위험 요소
- API 연동 이슈 또는 외부 의존성
- FE/BE 인터페이스 합의 필요 사항

### 4. 디자인 준비 상태 확인 (박소연, 15분)
- 개발 착수 가능한 디자인 완성 여부
- 미완성 화면 처리 방안 (스켈레톤 UI 등)
- 디자인 시스템 컴포넌트 재사용 여부

### 5. QA 계획 (정예린, 10분)
- 이번 스프린트 테스트 케이스 범위
- 가격 표시 정확성 검증 포인트
- 자동화 테스트 추가 대상

### 6. 태스크 분배 및 스토리 포인트 (전체, 10분)
- 각 태스크 담당자 배정
- 스토리 포인트 추정 (1/2/3/5/8)
- 스프린트 용량(capacity) 초과 여부 확인
