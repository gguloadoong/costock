## 이준혁 (PM) — 비전 & 범위

- **핵심 메시지**: 앱 수가 아니라 **맥락 전환 비용(90초)** 을 없애는 것
- 업비트·토스증권이 못 하는 구조적 이유 확정 (이해충돌 + 규제)
- CoStock 3대 승부처: 통합 검색 / 크로스에셋 맥락 연결 / 로그인 없는 진입장벽

**Sprint 1 DoD**
- 홈화면 3초 이내 로딩
- 실시간 가격 갱신
- 관심종목 추가 → 재방문 복원
- 이상값 stale 표시
- Lighthouse 모바일 80+

## 한서준 (Strategist) — 전략

- 진입 타이밍: 주식+코인 동시 보유 투자자 정착 변곡점 + 경쟁사 IPO 방어 국면
- **가장 결정적 경쟁사 약점**: 업비트의 이해충돌 구조 (해결 불가)
- **12개월 내 선점 필수**: 크로스에셋 맥락 연결 UX — 사용자 루틴화
- Phase 0 광고 현실: DAU 500 → 월 15~40만원 수준 (팀 운영비 불가)
- **Phase 0 실제 수익전략**: 토스증권 네이티브 스폰서 직접 영업 (월 500~1,000만원)
- **즉시 액션**: KIS API 법무 검토 → 최재원이 이번 주 KIS와 직접 확인
