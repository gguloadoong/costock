## 4. 팀별 발언

### 이준혁 (PM)
> "Phase 0 완료 기준(베타 1,000명, DAU 30% 2회 이상 방문, 가격 지연 3초 이내)을 달성하려면 이번 주 백엔드 라우트 3개 구현이 크리티컬 패스입니다. KIS API가 계속 막히면 대안을 이번 주 금요일까지 결정해야 합니다."

### 최재원 (BE)
> "KIS API 심사가 생각보다 길어지고 있습니다. 한국거래소 OpenAPI(정규장 15분 지연)와 Yahoo Finance(무료 티어) 두 가지를 내일까지 PoC 코드로 검토해보겠습니다. 검색과 가격 라우트는 Mock 데이터 기반으로라도 22일까지 구현 가능합니다."

### 김민준 (FE)
> "상세 페이지 컴포넌트는 이미 API 스펙대로 인터페이스가 분리되어 있어서 백엔드 라우트만 올라오면 연동은 빠릅니다. 일봉 차트는 TradingView 라이브러리 라이선스 검토가 먼저 필요한데, 오픈소스 버전(lightweight-charts)으로 우선 진행할게요."

### 박소연 (Designer)
> "뉴스 피드 UI는 카드형 레이아웃 스펙이 90% 완성됐습니다. 실제 API 응답 필드가 확정되면 바로 디자인 완료 가능합니다. 미구현 기능 중 JSON 내보내기 UI 스펙도 이번 주 안에 정리하겠습니다."

### 정예린 (QA)
> "현재 localStorage 기능, 검색 UI, 상세 페이지 기본 플로우 테스트 케이스 21일까지 작성 예정입니다. Mock → Real API 전환 시 가격 정확성 회귀 테스트가 핵심인데, 데이터 검증 기준값을 최재원님과 사전에 맞춰야 합니다."

### 한서준 (Strategist)
> "경쟁사 토스증권이 이달 코인 시범 서비스를 발표했습니다. 우리가 주식+코인 통합 뷰를 가장 먼저 완성하는 것이 포지셔닝에 중요합니다. KIS 대안 결정 후 베타 일정을 공격적으로 잡는 것을 추천합니다."
