**최종 수정**: 2026-03-18

---

## 1. 디자인 원칙

### 핵심 가치
1. **신뢰(Trust)**: 금융 앱은 신뢰가 생명 — 정확한 데이터, 안정적인 UI
2. **속도(Speed)**: 투자자는 빠른 정보 습득 요구 — 스캔 가능한 레이아웃
3. **통합(Integration)**: 주식+코인 이질감 없이 하나의 경험

## 2. 색상 체계


## 3. 타이포그래피

### 폰트 패밀리
```css
/* 숫자 — 정렬 일관성 필수 */
font-family: 'Roboto Mono', monospace;

/* 본문 텍스트 */
font-family: 'Pretendard', 'Apple SD Gothic Neo', sans-serif;
```

### 숫자 표시 규칙
```
가격:    ₩ 85,400  (천 단위 콤마, 원화 기호)

코인:    ₩ 142,850,000  (비트코인 단위 주의)
소수점:  최소 2자리 고정 (코인은 최대 8자리)
```

### 타입 스케일
```

heading-md:  18px / 600 (카드 타이틀)
body-lg:     16px / 400 (본문)
body-md:     14px / 400 (보조 정보)
caption:     12px / 400 (메타 정보)
mono-xl:     24px / 700 (현재가)
mono-lg:     18px / 600 (변동률)
```

## 4. 컴포넌트 스펙

### 가격 카드 (PriceCard)
```
┌─────────────────────────────┐
│ 삼성전자           005930   │
│ ₩ 85,400          KOSPI    │
│ +1,200 (+1.43%)  ▲         │  ← 빨간색
│ 거래량: 12,345,678          │
└─────────────────────────────┘
```

### 변동률 배지 (ChangeBadge)
```
상승: [+1.43%]  배경: #FEE2E2, 텍스트: #E84040
하락: [-0.89%]  배경: #DBEAFE, 텍스트: #2563EB
보합: [ 0.00%]  배경: #F3F4F6, 텍스트: #6B7280
```

### 캔들차트
- 상승 캔들: 빈 몸통(속이 빈) 또는 빨간색 채움 — 한국 관행 확인 후 결정
- 하락 캔들: 파란색 채움
- 이동평균선: MA5(#F59E0B), MA20(#8B5CF6), MA60(#10B981)

## 5. 레이아웃 가이드

### 모바일 (우선)
```
화면 너비: 375px (기준)
여백:      좌우 16px, 상단 20px
카드 간격: 8px
```

### 정보 밀도
- 투자자는 정보 밀도를 선호 — 빈 공간 최소화
- 스크롤보다 탭/필터로 화면 내 탐색
- 핵심 지표(현재가, 변동률) 항상 첫 시선에 위치

### 네비게이션 구조
```
홈 (⌂)
├── 관심종목 탭
├── 주식 탭
└── 코인 탭

탐색 (🔍)
시장 (📊)
├── 국내 지수
├── 해외 지수
└── 코인 시세

MY (👤)
```

## 6. 모션 & 애니메이션

### 가격 업데이트 애니메이션
```css
/* 가격 변동 시 깜빡임 효과 */
@keyframes priceFlash {
  0%   { background: transparent; }
  50%  { background: rgba(232, 64, 64, 0.2); } /* 상승 */
  100% { background: transparent; }
}
duration: 300ms
```

### 전환 효과
- 화면 전환: slide (150ms)
- 모달: fade + scale (200ms)
- 데이터 로딩: skeleton (pulse)

## 7. 접근성 (WCAG 2.1 AA)
- 색상만으로 정보 전달 금지 → 아이콘(▲▼) 병행
- 대비율: 4.5:1 이상 (일반 텍스트), 3:1 이상 (큰 텍스트)
- 터치 타겟: 최소 44×44px
- 스크린리더: aria-label 필수 (가격 변동 방향 명시)
