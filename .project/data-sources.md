## 1. 국내 주식

### 한국거래소 (KRX) 오픈API
- **URL**: https://openapi.krx.co.kr
- **제공 데이터**: 코스피/코스닥 종목 목록, 일별 시가총액, 주가 통계
- **갱신 주기**: 장 마감 후 (T+1)
- **인증**: API 키 (무료 신청)
- **제약**: 실시간 아님 — 이력 데이터 및 종목 기본정보용
- **용도**: 종목 마스터 데이터, 일봉 이력

### 금융위원회 공공데이터포털
- **URL**: https://www.data.go.kr (금융위원회 제공)
- **제공 데이터**: 주식 발행정보, ETF 정보, 상장폐지 이력
- **갱신 주기**: 일 1회
- **인증**: 공공데이터포털 API 키 (무료)
- **용도**: ETF 목록, 상장 정보 보완

### 한국투자증권 Open API (실시간)
- **URL**: https://apiportal.koreainvestment.com
- **제공 데이터**: 실시간 체결가, 호가, 주문 (계좌 연동)
- **갱신 주기**: 실시간 (WebSocket)
- **인증**: OAuth 2.0 (앱 키 + 시크릿)
- **비용**: 기본 무료, 고빈도 호출 시 유료 플랜
- **용도**: 실시간 주가 스트리밍 (메인 소스)
- **제약**: 장중(09:00-15:30)만 실시간

## 2. 코인

### 업비트 REST API
- **URL**: https://api.upbit.com/v1
- **제공 데이터**: 원화 마켓 코인 목록, 현재가, 일봉/분봉
- **갱신 주기**: REST 폴링 or WebSocket 실시간
- **인증**: 무료 (공개 API), 개인정보 필요 시 JWT
- **Rate Limit**: 분당 600 요청 (IP 기준)
- **용도**: 코인 실시간 가격 메인 소스
- **WebSocket**: wss://api.upbit.com/websocket/v1

### 빗썸 Public API
- **URL**: https://api.bithumb.com/public
- **제공 데이터**: 현재가, 호가, 거래내역
- **인증**: 불필요 (공개 API)
- **Rate Limit**: 초당 20 요청
- **용도**: 업비트 가격과 비교, 보조 소스
- **참고**: 업비트와 가격 차이 발생 시 — 재정거래 정보로 활용 가능

### CoinGecko API
- **URL**: https://api.coingecko.com/api/v3
- **제공 데이터**: 글로벌 코인 가격 (USD 기준), 시가총액, 도미넌스
- **인증**: 무료 플랜 (API 키 선택)
- **Rate Limit**: 분당 30 요청 (무료)
- **용도**: 글로벌 시장 데이터, BTC 도미넌스, 코인 기본 정보

## 3. 해외 주식 (Phase 1)

### Alpha Vantage
- **URL**: https://www.alphavantage.co
- **제공 데이터**: 미국 주식 실시간(15분 지연), 이력 데이터
- **인증**: API 키 (무료 플랜 500 req/day)
- **용도**: 나스닥/NYSE 일봉 데이터
- **제약**: 무료 플랜 지연 15분

### Yahoo Finance (비공식)
- **주의**: 공식 API 아님 — 약관 위반 가능
- **대안**: Financial Modeling Prep API (유료, 안정적)

## 4. 뉴스

### 네이버 금융 뉴스 RSS
- **URL**: https://finance.naver.com/news/news_list.naver?mode=LSS2D
- **제공 데이터**: 종목 관련 뉴스
- **갱신 주기**: 준실시간
- **인증**: 불필요
- **용도**: 국내 주식 관련 뉴스

### 네이버 검색 API (뉴스)
- **URL**: https://openapi.naver.com/v1/search/news
- **인증**: 네이버 앱 키
- **Rate Limit**: 일 25,000 요청
- **용도**: 종목명 기반 뉴스 검색

## 5. 데이터 수집 전략

### 수집 우선순위
```
실시간 (WebSocket):
  - 한국투자증권 API → 주식 체결가
  - 업비트 WebSocket → 코인 현재가

폴링 (1분 주기):
  - 빗썸 API → 코인 보조 확인
  - 시장 지수 (코스피/코스닥)

일배치 (장 마감 후):
  - KRX 오픈API → 종목 마스터 갱신
  - 뉴스 아카이브
```

### 장애 대응 (폴백)
```
한국투자증권 장애 → Redis 캐시 마지막 가격 표시 + "지연" 표시
업비트 장애        → 빗썸 API로 폴백
외부 API 전체 장애 → DB 마지막 저장가 표시 + 사용자 알림
```
