## 1. 서비스 비전 & 포지셔닝

### 비전 선언

"주식과 코인을 번갈아 보는 행동을 멈추게 한다."

단순히 두 자산을 한 화면에 올려놓는 것이 목표가 아니다. 투자자가 정보를 수집하는 동선 자체를 재설계하는 것이 핵심이다. CoStock은 국내 투자자의 실제 행동 패턴 — 주식 보다가 코인 확인하고, 코인 급등에 관련주를 검색하는 — 을 하나의 앱 안에서 완결시킨다.

### 실제 문제 정의

표면적으로는 "앱 여러 개"가 불편한 것처럼 보이지만, 진짜 문제는 다르다.

**맥락 전환 비용(Context Switching Cost)**: 투자자가 업비트에서 BTC가 갑자기 5% 급등하는 것을 봤을 때, "관련주 뭐가 있지?"라는 생각이 든다. 이 순간 네이버 검색 → 네이버증권 → 종목 검색의 흐름은 평균 90초 이상이 걸린다. 주가 급등락 장에서 90초는 기회를 놓치거나 손실을 키우는 시간이다.

**정보 단절이 만드는 인지 왜곡**: 주식 앱에서 코인을 볼 수 없으면, 투자자는 주식 수익률과 코인 수익률을 각각 다른 기준으로 평가한다. 통합된 시각이 없으면 전체 자산 관리가 불가능하다.

**재방문 이유의 부재**: 네이버증권은 정보는 많지만 "다시 켜야 할 이유"가 약하다. 업비트는 거래소 목적이어서 정보 탐색보다 체결이 목적이다. 순수 정보 서비스로서 매일 돌아올 이유를 만드는 플랫폼이 없다.

### 왜 업비트·토스증권이 이 공백을 못 메우는가 — 구조적 이유

업비트는 거래소다. 거래소의 수익은 거래 수수료에서 나온다. 업비트가 주식 정보를 잘 보여줄수록 사용자는 업비트 안에서 코인 거래를 덜 한다. 주식 정보 제공은 업비트의 핵심 비즈니스 모델과 이해충돌 구조다.

토스증권은 증권사 면허를 보유하고 MTS로 수익을 낸다. 코인은 자본시장법상 증권이 아니며, 코인 정보를 전면에 내세우면 규제 리스크 및 브랜드 포지셔닝 혼란이 발생한다. 토스가 코인을 다루려면 별도 법인이나 파트너십 구조가 필요하고, 이는 단기간에 실행 불가능하다.

네이버증권은 광고 기반 미디어 사업이다. 네이버의 의사결정 단위에서 증권 섹션은 네이버 포털 전체 서비스 중 하나일 뿐이다. 코인 정보를 깊게 통합하려면 별도의 전담 팀과 규제 대응이 필요한데, 이는 네이버 조직 구조상 우선순위에 오르기 어렵다.

**결론**: 이 세 플레이어 모두 구조적 이유로 이 공백을 채울 동기가 없다. CoStock에게 이것은 시장 진입 창이다.

### 포지셔닝

```
                    [코인 정보 깊이]
                          ↑
           업비트 •       |
                          |                   • CoStock (목표)
           빗썸 •         |
                          |
[주식 약] ————————————————+———————————————— [주식 깊이]
                          |
                          |    • 토스증권
                          |
                          |         • 네이버증권
                          ↓
                    [코인 정보 없음]
```

CoStock이 실제로 이길 수 있는 영역:
- **통합 검색**: 종목명 하나로 주식·코인 동시 탐색
- **크로스에셋 맥락 연결**: 코인 급등 시 관련 테마주 즉시 노출
- **재방문 루틴화**: 매일 아침 시장 전체를 한 번에 훑는 앱으로 포지셔닝
- **로그인 없는 낮은 진입장벽**: 설치 후 즉시 사용 가능 (경쟁사는 모두 회원가입 유도)

## 2. 타겟 사용자 — 심층 페르소나

### 페르소나 A — "크로스 체커" (핵심 타겟)

**프로필**: 김도현, 27세, 개발자, 서울 거주
**투자 규모**: 코인 1,200만원 / 국내 주식 800만원
**사용 기기**: iPhone 주 사용, 맥북 업무용

**실제 행동 패턴 (관찰 기반)**

오전 8시 50분, 지하철 안. 출근 전 10분이 핵심 정보 수집 시간이다. 업비트를 먼저 켜서 BTC·ETH 야간 흐름 확인, 토스증권으로 전환해 보유 삼성전자·카카오 전일 종가 확인. 두 앱을 왔다 갔다 하는 데 8분, 실제 정보를 처리하는 데 2분 남는다.

오후 3시, 시장 마감 전후. 주식 시장 마감 직전 급등락이 생기면 코인 시장과의 연관성을 체감한다. "미국 금리 이슈로 주식 떨어지면 비트코인도 떨어지는데, 지금 BTC는 어떻지?" — 이 질문에 답하려면 두 앱을 동시에 봐야 한다.

저녁 11시, 미국 선물 시장 개장 후. 나스닥 선물 흐름을 보며 다음날 국내 시장 예측을 시도한다. 이 시간에 코인도 함께 움직인다.

**실제 불편 (표면 아래)**

불편의 핵심은 속도가 아니라 맥락의 단절이다. 코인과 주식이 같은 거시경제 환경에 반응하는데, 각각 다른 앱에서 보면 이 연관성을 직관적으로 파악할 수 없다. "비트코인이 오르는데 왜 가상자산 관련주는 안 오르지?"라는 질문을 실시간으로 해결할 도구가 없다.

**CoStock에서 원하는 것**

즉각적인 크로스에셋 조회. 코인 탭에서 BTC 급등을 보는 순간, 같은 화면에서 "관련 테마주: 두나무(323280), 빗썸코리아" 같은 연결이 보이면 된다. 로그인 없이 관심종목 저장 — 처음 켰을 때부터 내가 원하는 종목을 즉시 등록하고 다음에 와도 그대로 있어야 한다.

---

### 페르소나 B — "확장 중인 주식 투자자" (성장 타겟)

**프로필**: 박정숙, 46세, 중소기업 임원, 경기 분당 거주
**투자 규모**: 국내 주식 4,500만원 / 최근 코인 200만원 시작
**사용 기기**: 갤럭시 S 시리즈, 회사 PC

**실제 행동 패턴**

네이버증권 15년 사용자다. 즐겨찾기에 삼성전자·현대차·POSCO 등 10개 종목이 저장되어 있다. 최근 자녀 세대가 코인 얘기를 자주 하고 뉴스에서 가상자산 이슈가 많아지자 소액으로 비트코인을 매수했다. 업비트 앱을 깔았지만 인터페이스가 낯설고, 코인 가격이 얼마나 올랐는지 확인하려면 별도로 앱을 켜야 해서 번거롭다.

**핵심 심리**

"코인은 모르겠고, 내가 보유한 비트코인이 오늘 얼마인지 주식 볼 때 같이 볼 수 있으면 좋겠다." 코인 전문 정보는 필요 없다. 내 보유 자산 한 줄이면 충분하다. 복잡한 코인 거래 기능은 부담스럽다.

**CoStock에서 원하는 것**

기존 주식 UX와 동일한 인터페이스에 코인 한 줄이 추가되는 경험. 별도 가입 없이 "비트코인을 관심종목에 추가"하면 주식 목록과 함께 보이는 것. 학습 비용이 0에 가까워야 한다.

---

### 페르소나 C — "정보 습득형 루키" (장기 육성 타겟)

**프로필**: 이수진, 24세, 사회 초년생, 서울 마포 거주
**투자 규모**: 주식 50만원 / 코인 30만원 (소액 시작)
**사용 기기**: iPhone, 주로 이동 중 사용

**실제 행동 패턴**

투자를 시작한 지 3개월. 유튜브로 투자 공부를 하고, 트위터(X)와 네이버 카페에서 주식·코인 뉴스를 본다. 네이버증권은 정보가 너무 많아서 어디를 봐야 할지 모르겠다. 업비트는 차트를 읽을 줄 모른다. 어떤 앱도 "처음 보는 사람"을 위한 설계가 아니다.

**핵심 니즈**

정보가 많은 것보다 이해할 수 있는 정보. "삼성전자가 오늘 2% 올랐다"는 숫자보다 "왜 올랐는지"가 보이면 더 오래 앱을 본다. 처음 진입 장벽이 낮아야 한다 — 로그인 화면은 이탈 유도다.

## 3. User Journey

### 핵심 전제: 회원가입/로그인 없음

CoStock은 인증 시스템을 MVP에 포함하지 않는다. 모든 사용자 설정(관심종목)은 브라우저의 localStorage에 저장된다. 이 결정의 근거와 트레이드오프는 아래에 명시한다.

---

### 3-1. 첫 방문 Journey

**진입 경로**: 검색 광고, 소셜 미디어 링크, 지인 공유 URL

**0-30초 — 첫인상 결정 구간**

랜딩 시 로그인 화면 없음. 즉시 시장 현황이 보인다. 코스피·코스닥 지수, BTC·ETH 현재가, 상위 등락 종목 5개. 아무것도 클릭하지 않아도 오늘 시장의 핵심을 파악할 수 있어야 한다.

이 30초 안에 "정보가 맞네, 빠르네, 주식이랑 코인이 같이 있네"를 느끼게 하는 것이 목표다.

**30초-3분 — 탐색 구간**

검색창에 관심 종목을 입력한다. "삼성전자"를 치면 주식 결과가, "비트코인"을 치면 코인 결과가, "BTC"를 치면 코인이 즉시 나온다. 주식과 코인을 따로 구분할 필요 없이 하나의 검색으로 해결된다.

종목 상세 페이지에서 현재가, 일봉 차트, 기본 정보(시가총액, 거래량)를 본다.

**3분-10분 — 가치 인식 구간**

"관심종목 추가" 버튼을 누른다. 로그인 팝업이 뜨지 않는다. 바로 추가된다. localStorage에 저장된다.

홈으로 돌아오면 방금 추가한 종목이 관심종목 탭에 보인다. 이 경험이 재방문의 씨앗이다.

---

### 3-2. 재방문 Journey

**재방문 유도 메커니즘 (가입 없는 서비스의 핵심 과제)**

가입 없는 서비스에서 retention의 유일한 무기는 **콘텐츠 루틴**이다. 사용자가 "매일 아침 이 앱을 켜야 한다"는 습관을 만들어야 한다.

구체적 메커니즘:

1. **관심종목 즉시 로드**: 재방문 시 내가 저장한 종목이 첫 화면에 바로 보인다. 이것이 재방문의 가장 강력한 이유다. "내 것"이 있는 앱은 다시 온다.

2. **시장 개장/마감 알림**: PWA(Progressive Web App) 방식의 브라우저 푸시 알림. 로그인 없이도 알림 수신 동의를 받을 수 있다. 오전 9시 개장 알림, 오후 3시 30분 마감 요약 알림. 이 두 번의 알림이 일 방문 2회를 만든다.

3. **오늘의 급등락 카드**: 매일 업데이트되는 주식+코인 통합 급등락 TOP 5. 매일 다른 콘텐츠가 재방문 이유를 제공한다.

4. **관심종목 연관 뉴스**: 내가 저장한 종목과 관련된 뉴스가 홈 피드에 노출된다. 관심종목이 많을수록 피드가 개인화된다.

---

### 3-3. 헤비유저 Journey

**7일 이상 재방문 사용자의 행동 패턴**

관심종목이 10개 이상으로 늘어난다. 주식 5개, 코인 5개 혼합. 매일 아침 오전 9시 이전에 앱을 켜서 관심종목 전체 현황을 30초 안에 스캔한다. 이 행동이 루틴화된 사용자가 핵심 지표(일 방문 2회, 체류 7분)를 달성하는 세그먼트다.

이 단계에서 사용자는 관심종목 그룹 기능, 분봉 차트, 종목 비교 등 심화 기능의 필요성을 느끼기 시작한다. 이때 "더 많은 기능은 북마크 저장 후 사용"이 아니라 "이 앱을 계속 써야겠다"는 심리를 강화하는 기능을 P1에 배치한다.

---

### 3-4. localStorage 기반 관심종목 UX 설계

**저장 구조**

```json
{
  "watchlist": [
    { "id": "KR_005930", "type": "stock", "name": "삼성전자", "addedAt": 1742000000 },
    { "id": "KRW-BTC", "type": "crypto", "name": "비트코인", "addedAt": 1742000001 }
  ],
  "preferences": {
    "theme": "light",
    "defaultTab": "watchlist"
  }
}
```

**디바이스 종속 문제와 UX 처리**

localStorage는 디바이스와 브라우저에 종속된다. 핸드폰에서 저장한 관심종목이 PC에서 보이지 않는다. 이것은 실제 사용자 불만으로 이어질 수 있다.

MVP에서의 대응:
- 첫 방문 시 안내 문구 표시: "관심종목은 이 기기에 저장됩니다. 여러 기기에서 동기화하려면 [알림 신청]으로 추후 지원 예정입니다."
- 관심종목 목록을 URL 쿼리 파라미터로 공유하는 기능 제공: `costock.kr/?w=005930,KRW-BTC` — 이 링크를 북마크하면 어느 브라우저에서나 동일 목록 복원 가능
- localStorage 초기화 경고: 브라우저 캐시 삭제 전 내보내기 기능 (JSON 다운로드)

**저장 한계**

localStorage 용량 한계는 도메인당 5-10MB. 관심종목 100개 기준 저장 데이터는 수 KB 수준으로 한계에 도달하지 않는다.

## 4. 경쟁사 분석 — 구조적 약점

### 4-1. 직접 경쟁사 심화 분석

**토스증권**

강점: 2019년 이후 국내 금융 앱 중 UX 혁신을 주도. 간편 투자 온보딩, 소수점 투자, 해외주식 접근성 개선. MAU 300만 (2024년 기준).

구조적 약점: 증권업 면허 사업자다. 코인을 서비스하려면 가상자산사업자(VASP) 등록이 별도로 필요하다. 토스는 이미 토스뱅크, 토스페이먼츠 등 금융 라이선스 포트폴리오가 복잡하다. 코인 정보를 "중립적 정보 서비스"로 제공하더라도 한국 투자자들은 코인 정보 = 투자 권유로 받아들이는 경향이 있어 규제 해석 리스크가 있다. 또한 토스의 UX 팀은 주식 전문가들로 구성되어 있어 코인 UI/UX 패턴에 대한 학습 비용이 존재한다.

**CoStock이 이길 수 있는 지점**: 코인+주식 통합 정보를 규제 리스크 없이 제공할 수 있는 포지셔닝. CoStock은 증권사가 아닌 정보 서비스다.

---

**업비트 (두나무)**

강점: 국내 코인 거래량 점유율 70% 이상. 브랜드 신뢰도 1위. 실시간 데이터 인프라 업계 최고 수준.

구조적 약점: 거래소 비즈니스 모델과 정보 플랫폼 비즈니스 모델의 이해충돌. 업비트가 주식 정보를 잘 보여줄수록 사용자가 주식으로 자금을 이동할 동기가 생기고, 코인 거래량이 줄어들 수 있다. 업비트의 UI는 거래 중심으로 설계되어 있어 "정보 탐색" 사용자 경험이 약하다. 주식 정보를 추가하면 UI 복잡도 급증과 기존 사용자 혼란 가능성이 있다.

**CoStock이 이길 수 있는 지점**: 거래 기능 없이 순수 정보 탐색에 최적화된 UX. 업비트 사용자가 "가격 확인"만 하러 올 때의 더 나은 대안.

---

**네이버증권**

강점: 월간 UV 2,000만 이상 (2024년 기준). 방대한 재무 데이터, 뉴스 연동. 포털 트래픽 기반의 자연 유입.

구조적 약점: 네이버의 증권 섹션은 광고 미디어다. 사용자 경험 최적화보다 광고 노출 최대화에 설계가 맞춰져 있다. 정보 밀도가 높지만 UX가 2010년대 PC 기준에 머물러 있다. 모바일 앱 UX가 열악하다. 코인 정보는 CoinMarketCap 기준으로 제공하지만 주식 데이터와 통합되어 있지 않다.

**CoStock이 이길 수 있는 지점**: 모바일 퍼스트, 주식+코인 통합 UX. 네이버는 모바일에서 이기기 어려운 구조다.

### 5-3. localStorage 관심종목 UX 상세 스펙

**관심종목 추가 플로우**

1. 종목 검색 결과 또는 종목 상세 페이지에서 [+ 추가] 버튼 탭
2. 로그인 팝업 없음. 즉시 localStorage에 저장
3. 하단에 토스트 메시지: "관심종목에 추가되었습니다. 이 기기에 저장됩니다."
4. 홈 화면 관심종목 탭에 즉시 반영

**처음 방문 사용자 온보딩 (관심종목 0개 상태)**

관심종목 탭 빈 화면에 "자주 보는 종목을 추가하세요" + 예시 종목 5개 (삼성전자, 현대차, 비트코인, 이더리움, NAVER) 퀵 추가 버튼. 이 5개 중 하나만 눌러도 즉시 관심종목이 생기고 재방문 이유가 만들어진다.

**관심종목 백업/복원 (디바이스 이전 대응)**

- 설정 메뉴 > "관심종목 내보내기": JSON 파일 다운로드 또는 공유 URL 생성
- 공유 URL 형식: `https://costock.kr/import?w=KR_005930,KR_000660,KRW-BTC`
- URL 접속 시 "관심종목 3개를 가져오시겠습니까?" 확인 팝업

## 6. 수익화 전략

### 6-1. 기본 방향

### 6-2. 광고 수익 (Phase 0~1, 즉시 실행 가능)

**디스플레이 광고**

네이버 성과형 광고(GFA) 또는 Google AdSense 연동. 배너 위치: 뉴스 피드 사이, 종목 상세 하단. 금융 앱 CPM 기준 약 3,000~8,000원/1,000회 노출. DAU 1만, 1인당 일 10회 노출 가정 시 월 약 90만~240만원.

**금융 광고 집행 시 준수 사항**: 투자 상품 광고는 금융소비자보호법상 적합성 원칙 고지 필요. CoStock은 광고 게재 플랫폼이므로 광고주(증권사, 코인거래소)가 적합성 고지를 직접 처리하도록 광고 약관에 명시.

**네이티브 스폰서 섹션**

증권사·코인거래소의 "오늘의 이벤트" 배너. 업비트 수수료 이벤트, 토스증권 주식 증정 이벤트 등. 직접 영업 필요. 월 계약 기준, 건당 500만~2,000만원 예상.

---

### 6-3. 프리미엄 기능 (Phase 2, 자발적 가입 유도)

가입 없는 서비스에서 유료 전환을 유도하려면 "가입의 가치"가 명확해야 한다.

**가입 가치 제안 (로그인 없는 사용자에게 노출)**

- "관심종목을 PC와 모바일에서 함께 보려면 계정을 만드세요" — 다기기 동기화
- "가격 알림을 받으려면 계정이 필요합니다" — 특정 가격 도달 알림
- "포트폴리오 수익률을 계산하려면 계정을 만드세요"

이 세 가지 가치를 무료 가입으로 해결하고, 그 위에 유료 프리미엄을 얹는 구조.

**프리미엄 월 9,900원 구성 (Phase 2)**

**문제**: 로그인이 없으면 D30 리텐션을 정확히 측정할 수 없다.

**대안 측정 방법**:

1. **쿠키 기반 코호트**: GA4의 퍼스트파티 쿠키로 신규 방문자를 식별하고, 30일 이내 재방문 여부 측정. 정확도는 70-80% 수준 (쿠키 삭제 케이스 제외).

2. **관심종목 보유자 재방문율**: localStorage에 관심종목이 1개 이상인 사용자의 재방문율 별도 추적. 이것이 실질적인 "활성 사용자" 지표가 된다. 목표: D30 재방문율 35% 이상.

3. **푸시 알림 클릭률**: 브라우저 푸시 알림 수신 동의자의 클릭률 측정. 목표: 20% 이상. 이 지표가 가장 정확한 활성 사용자 지표.

## 8. 리스크 & 제약사항

### 8-1. 법적 규제 제약

**자본시장법**

금융투자업 인가 없이는 "투자 권유"를 할 수 없다. CoStock은 정보 서비스로 포지셔닝하므로 다음을 명확히 준수해야 한다.

- 금지: "이 종목은 상승할 것으로 예상됩니다" 등 예측·권유 표현
- 금지: 수익률 보장 암시 표현
- 허용: 가격 데이터, 차트, 재무 정보, 뉴스의 중립적 제공
- 허용: "관련 종목" 정보 연결 (추천이 아닌 정보로 표시)

서비스 약관에 "투자 정보 제공 서비스이며 투자 권유가 아님"을 명시. 모든 페이지 하단에 면책 고지 필수.

**한국거래소(KRX) 실시간 주가 약관**

KRX는 실시간 주가 데이터 재배포에 대해 약관을 규정한다. 한국투자증권 Open API를 통해 수신하는 경우, KIS의 약관이 적용되며 상업적 재배포에 제한이 있을 수 있다. **법무 검토 필수 사항**: KIS API 약관상 CoStock의 서비스 형태(비가입 공개 서비스에서의 실시간 주가 표시)가 허용 범위인지 확인. 필요 시 KRX와 직접 계약 또는 데이터 딜레이(15분 지연) 적용.

**개인정보보호법**

가입 없는 서비스이므로 수집하는 개인정보는 최소화된다. 단, 브라우저 쿠키 및 IP 주소는 개인정보에 해당할 수 있다. GA4 사용 시 개인정보처리방침에 쿠키 수집 및 Google 공유 사실 명시 필수. 쿠키 동의 배너는 GDPR 대응이 아니더라도 국내 개인정보보호법 기준으로도 권고된다.

**광고 게재 시 금융광고 규제**

증권사·코인거래소 광고를 게재할 경우, 해당 광고가 금융소비자보호법상 금융광고 심의 대상이다. 광고주가 심의를 완료한 광고만 게재하도록 계약서에 명시.

### 8-2. localStorage 한계 — 기술적 제약

| 한계 | 영향 | 대응 방안 |
|------|------|----------|
| 디바이스 종속 | 멀티기기 사용자 불편 | 공유 URL 기능, Phase 2에서 선택적 계정 연동 |
| 브라우저 캐시 삭제 시 소멸 | 관심종목 분실 | 내보내기 기능, 사용자 안내 |
| Safari ITP (지능형 추적 방지) | 7일 이후 localStorage 만료 가능성 | 주기적 데이터 갱신 메커니즘, 혹은 IndexedDB로 전환 검토 |
| 시크릿 모드 | 저장 불가 | 시크릿 모드 감지 후 안내 배너 표시 |
| 용량 한계 (5-10MB) | 대용량 데이터 저장 불가 | 관심종목은 ID만 저장, 실제 가격 데이터는 서버에서 조회 |

**Safari ITP 대응 상세**: iOS Safari는 `localStorage`를 7일 이후 만료시키는 경우가 있다 (사이트 방문 없을 경우). 이에 대비해 `IndexedDB`를 우선 사용하고 `localStorage`를 폴백으로 사용하는 구조 권장. IndexedDB는 ITP 적용에서 제외된다.

### 8-4. 비즈니스 리스크

**가입 없는 서비스의 수익화 한계**: 광고 수익은 트래픽에 선형 비례한다. DAU 1만 수준에서는 광고만으로 팀 인건비를 충당하기 어렵다. Phase 2의 프리미엄 구독 전환이 늦어지면 런웨이가 소진될 위험이 있다. 대응: Phase 1(출시 후 3개월)에서 네이티브 스폰서 영업을 병행하여 초기 고정 수익 확보.

**경쟁사 대응 리스크**: 토스증권 또는 네이버가 코인 정보 통합을 발표하면 CoStock의 차별화가 약화된다. 대응: 토스·네이버가 구조적으로 따라오기 어려운 영역(크로스에셋 연관 분석, 코인+주식 통합 알림)을 Phase 1~2에서 선제적으로 구축.
