## 1. 제품 개요 및 비전

### 비전 선언

"AI가 매매할 때 가장 먼저 안다. 당신이 판단하고, 당신이 실행한다."

CoStock은 AI 트레이더가 실제로 모의 매매하는 순간을 실시간으로 공개하고, 구독한 사용자에게 즉시 푸시 알림을 보내는 서비스다. 자동 실행은 없다. 알림을 받은 사용자가 직접 판단하고 직접 매수/매도한다. 복잡한 차트 분석 없이, AI의 매매 타이밍을 참고해 본인 판단으로 투자하는 경험을 설계한다.

### 서비스 정의

**CoStock v2.1**은 AI 봇이 모의투자(페이퍼 트레이딩)를 수행하고, 구독자에게 매매 신호를 푸시 알림으로 전달하는 **모바일 웹 서비스(Next.js PWA)**다.

- 취급 자산: 코인(바이낸스/업비트), 국내주식, 미국주식
- 플랫폼: Next.js 14 PWA (모바일 웹. 앱스토어 배포 없음.)
- 핵심 포지셔닝: "AI 매매 신호를 가장 먼저, 투명하게 알려주는 서비스"
- **카피트레이딩 정의**: 자동 주문 실행 없음. "카피 = 특정 AI 트레이더를 구독하면 매수/매도 시 푸시 알림 수신"이 전부.

### 플랫폼 결정 근거

| 항목 | React Native (앱) | Next.js PWA (웹) | 결정 |
|------|------------------|-----------------|------|
| 출시 속도 | 앱스토어 심사 1~2주 소요 | 즉시 배포 가능 | PWA 우위 |
| 투자 앱 심사 리스크 | 금융 카테고리 거절 사례 있음 | 해당 없음 | PWA 우위 |
| 푸시 알림 | FCM/APNS 모두 지원 | Web Push (FCM) | 동등 |
| 개발 속도 | 네이티브 빌드 환경 필요 | 단일 코드베이스 | PWA 우위 |
| 오프라인 | 제한적 | Service Worker | 동등 |

결론: MVP 기간(8주)에는 앱스토어 리스크와 개발 속도를 감안해 Next.js PWA로 출시. 사용자 반응 확인 후 Phase 1에서 네이티브 앱 여부 재검토.

### 왜 지금인가

- 국내 개인투자자 1,400만 명 중 60% 이상이 "어떤 종목을 사야 할지 모르겠다"는 니즈 (2025 한국투자자보호재단 설문)
- AI 매매 신호를 실시간으로 공개하는 국내 서비스 없음
- 자동 실행 없는 "알림만" 모델은 법적 리스크(일임 운용) 회피 가능 → 빠른 출시

## 2. 타겟 사용자 & 페르소나

### 주요 타겟

20~40대, 투자 경험이 없거나 적은 직장인. 투자에 관심은 있지만 공부할 시간이 없거나, 기존에 주먹구구식으로 투자하다 손해를 본 경험이 있는 사람.

### 페르소나 A — "시작하려는 이정민 (29세, 직장인)"

- 배경: 중견기업 마케터. 월 소득 340만 원. 재테크 유튜브를 즐겨보지만 막상 투자 계좌를 개설하고 종목을 고르는 것이 두렵다.
- 현재 행동: 적금만 유지. 친구들이 주식/코인으로 수익 냈다는 이야기에 자극을 받음.
- 페인 포인트: "어떤 종목을 살지 모르겠다", "차트는 어려워서 보기 싫다", "내가 고르면 왠지 떨어질 것 같다".
- 원하는 것: 믿을 수 있는 누군가(무언가)가 대신 판단해주면 그냥 따라하겠다.
- CoStock 사용 시나리오: AI-알파가 삼성전자를 매수했다는 푸시 알림 수신 → 앱 열어서 매수 근거 확인 → 본인 MTS에서 직접 매수 실행.

### 페르소나 B — "바쁜 투자자 김도훈 (38세, 스타트업 팀장)"

- 배경: 8년차 주식 투자 경험. 코인은 2021년 불장에 잠깐 참여. 바빠서 매일 시세 확인이 어렵다.
- 현재 행동: 장기 보유 위주지만 단기 기회를 놓치는 것이 아쉬움.
- 페인 포인트: "미국장 볼 때마다 새벽에 일어나야 한다", "좋은 타이밍을 놓친다".
- 원하는 것: 내 대신 모니터링하고, 좋은 타이밍에 알려주는 시스템.
- CoStock 사용 시나리오: AI-감마(미국주식 퀀트) 구독 → 매수 알림 수신 → 본인이 내용 확인 후 증권사 앱에서 직접 매수.

### 페르소나 C — "코인 입문자 박지수 (24세, 대학원생)"

- 배경: 코인에 관심이 많지만 어떤 알트코인을 살지 모르겠음. 비트코인만 소액 보유 중.
- 현재 행동: 코인 커뮤니티 눈팅. 인플루언서 유튜브 따라하다 손해 본 경험.
- 페인 포인트: "유튜버 말 믿었다가 손해봤다", "24시간 모니터링 불가".
- 원하는 것: 감정 없이 데이터로만 판단하는 믿을 수 있는 시스템.
- CoStock 사용 시나리오: AI-베타(코인 역추세) 구독 → 이더리움 매수 알림 → 업비트에서 직접 매수 실행.

## 3. 경쟁사 분석

### 직접 경쟁사

| 서비스 | 국가 | 모델 | 강점 | 약점 |
|--------|------|------|------|------|
| **eToro** | 글로벌 | 사람 트레이더 카피트레이딩 | 3,500만 사용자, 브랜드 신뢰 | 한국 미출시, 자동 실행이라 법적 리스크 |
| **에임(AIM)** | 한국 | AI 자동 포트폴리오 | 규제 준수(일임), 로보어드바이저 | 수익률 평범, AI 판단 과정 불투명 |
| **핀트(Fint)** | 한국 | AI 자동 ETF 투자 | 소액 시작 가능 | AI 판단 불투명, 코인 미지원 |
| **불리오** | 한국 | 퀀트 기반 자동투자 | 전략 다양 | 기술 허들 높음, 일반인 접근 어려움 |

### CoStock의 차별화

1. **AI 매매 행동 실시간 공개**: 에임/핀트는 AI가 무엇을 하는지 보여주지 않음. CoStock은 매수/매도 근거를 실시간 피드로 노출.
2. **코인+국내주식+미국주식 통합**: 국내 경쟁사 중 세 자산군을 모두 다루는 AI 투자 정보 서비스 없음.
3. **법적 안전한 구조**: 자동 실행 없음. 알림 수신 → 사용자 직접 판단 → 사용자 직접 실행. 일임 운용 규제 해당 없음.
4. **앱스토어 없는 즉시 배포**: PWA로 링크 공유만으로 사용 시작 가능. 바이럴 확산에 유리.

### P0 — AI 트레이더 목록 (홈)

**정의**: 서비스에 등록된 AI 트레이더를 수익률 기준으로 랭킹 표시. 앱 진입 첫 화면.

**카드 포함 정보**:
- AI 트레이더 이름 + 아바타 + 전략 태그 (예: "모멘텀", "역추세", "퀀트")
- 누적 수익률 (시작 이후 총 수익률)
- 이번 달 수익률
- 승률 (전체 청산 포지션 기준)
- 현재 보유 포지션 수
- 구독 여부 표시 (구독 중 배지)

**정렬 기준**: 기본값은 누적 수익률. 이번 달 수익률 / 승률로 전환 가능.

### P0 — 트레이더 상세 — 활동 생중계 피드

**정의**: 특정 AI 트레이더의 최근 매매 내역과 현재 보유 포지션을 실시간으로 보여주는 화면. "활동 생중계"라는 컨셉으로 SNS 피드 형태로 표시.

**탭 구성**:

#### 탭 1 — 활동 피드
- 최근 매매 이벤트 타임라인 (최신순)
- 피드 카드 포함 정보:
  - 행동: 매수 / 매도 / 포지션 추가
  - 종목명 + 티커 + 자산 유형 (코인/국내주식/미국주식)
  - 매수가 / 매도가
  - 수익률 (매도 시: 실현 수익률. 매수 시: 현재 평가 수익률.)
  - 매매 근거 1~2줄 (AI 생성 텍스트)
  - 시간 스탬프

#### 탭 2 — 보유 포지션
- 현재 보유 중인 포지션 목록
- 포지션 카드: 종목명 / 매수 평균가 / 현재가 / 평가 수익률 / 보유 기간 / 포트폴리오 내 비중

#### 탭 3 — 성과 요약
- AI 트레이더 전략 설명 (1~3줄)
- 누적 수익률 / 이번 달 수익률 / 승률 / MDD / 운용 시작일
- 월별 수익률 히스토리 바 차트 (최근 6개월)

### P0 — 매수/매도 푸시 알림

**정의**: 사용자가 특정 AI 트레이더를 구독하면, 해당 AI가 매수/매도할 때 즉시 Web Push 알림 수신. 자동 주문 실행 없음. 알림 수신 후 사용자가 직접 판단하고 직접 거래소/증권사에서 실행.

**알림 텍스트 예시**:
```
[AI-알파] 삼성전자 매수
RSI 과매도 + 기관 순매수 포착. 매수가 72,300원
→ 현재 AI 포트폴리오 확인하기
```

**알림 설정 옵션**:
- 구독할 AI 트레이더 선택 (다중 선택)
- 알림 유형: 매수 알림 ON/OFF / 매도 알림 ON/OFF (트레이더별 개별 설정)
- 방해 금지 시간대: 설정 시 해당 시간대 알림 차단 (예: 23:00~07:00)

**알림 딥링크**: 알림 탭 시 해당 트레이더 상세 → 활동 피드 탭으로 이동.

**Web Push 구현**: Firebase Cloud Messaging(FCM) Web Push API 사용. Service Worker에서 수신 처리.

### P0 — 실현손익 (월별 → 일별 드릴다운)

**정의**: AI 트레이더가 포지션을 청산할 때마다 실현손익을 기록하고, 월별 → 일별 리스트로 보여주는 화면. 트레이더 상세 페이지 내 별도 탭 또는 독립 화면.

**월별 요약 리스트**:
- 월 이름 (예: "2026년 3월")
- 해당 월 총 실현손익 (금액 + %)
- 거래 건수 / 수익 거래 수 / 손실 거래 수

**월 항목 탭 → 일별 드릴다운**:
- 해당 월 날짜별 거래 리스트
- 각 거래 항목: 종목명 / 자산 유형 / 매수일 / 매도일 / 매수가 / 매도가 / 수익률 / 실현손익

**상단 고정 — 전체 성과 요약**:
- 총 운용 기간
- 총 실현손익
- 연환산 수익률 (CAGR)
- 최고 월 / 최저 월

### P0 — 알림 설정 화면

**정의**: 사용자가 구독할 AI 트레이더를 선택하고, 각 트레이더별로 매수/매도 알림을 ON/OFF하는 화면.

**화면 구성**:
- 전체 AI 트레이더 목록 표시 (MVP: 3명)
- 각 트레이더 행:
  - AI 이름 + 전략 태그 + 누적 수익률
  - 구독 토글 (ON/OFF)
  - 구독 ON 시 확장: 매수 알림 토글 / 매도 알림 토글
- 방해 금지 시간대 설정 (전체 적용)
- 알림 권한 미허용 시 안내 배너 + 브라우저 설정 유도

## 5. 화면 구성

### 네비게이션 구조

```
하단 탭 바

```

### 화면 목록 (MVP 핵심 4개)

#### 핵심 화면 1 — 홈: AI 트레이더 목록

**목적**: 서비스 첫인상. AI 트레이더 3명의 수익률 랭킹을 한눈에 보여줌.

**레이아웃**:

## 6. AI 트레이더 설계

### 기본 원칙

- 모든 AI 트레이더는 페이퍼 트레이딩(모의투자)만 수행. 실제 자금 운용 없음.
- 각 AI는 가상의 시작 원금(1억 원)으로 시뮬레이션.
- 전략은 공개 알고리즘 기반. 매매 근거 텍스트로 투명하게 공개.
- 매매 판단 근거를 요약 텍스트로 실시간 생성 (LLM 활용).

### AI 트레이더 라인업 (MVP 5명)

> v2.2 업데이트: 초기 계획(3명)에서 델타·엡실론 추가. 자산군·전략 다양성 확보 및 사용자 선택폭 확대 목적.

#### 1. AI-알파 (Alpha)
- 전략: 모멘텀 추종
- 대상: 국내주식
- 로직: 52주 신고가 근처 종목 + 거래량 급증 + 외국인/기관 순매수 동반 시 진입. 5% 손절, 15% 익절 자동 청산.
- 성격: 공격적. 단기 (평균 보유 2~7일).
- 태그: #모멘텀 #단기 #국내주식
- 알림 빈도 예상: 주 2~5회 (국내 장 중 신호 발생 시)

#### 2. AI-베타 (Beta)
- 전략: 역추세 (평균회귀)
- 대상: 코인 (비트코인, 이더리움, 주요 알트)
- 로직: RSI 30 이하 과매도 + 볼린저밴드 하단 이탈 시 진입. 시장 공포지수(Fear & Greed) 20 이하 시 포지션 확대.
- 성격: 수비적. 중기 (평균 보유 1~4주).
- 태그: #역추세 #코인 #중기
- 알림 빈도 예상: 주 1~3회 (24시간 운영)

#### 3. AI-감마 (Gamma)
- 전략: 퀀트 팩터
- 대상: 미국주식
- 로직: 저PER + 고ROE + 낮은 부채비율 + 최근 3개월 주가 상승 종목 스크리닝. 월 1회 리밸런싱.
- 성격: 보수적. 장기 (평균 보유 1~3개월).
- 태그: #퀀트 #가치 #미국주식
- 알림 빈도 예상: 월 2~4회 (리밸런싱 + 신규 편입 시)

#### 4. AI-델타 (Delta)
- 전략: 추가 예정 (구현 완료, 전략 문서화 진행 중)
- 태그: 확인 후 업데이트

#### 5. AI-엡실론 (Epsilon)
- 전략: 추가 예정 (구현 완료, 전략 문서화 진행 중)
- 태그: 확인 후 업데이트

### AI 트레이더 매매 실행 로직

```
[데이터 수집 레이어]
  실시간 가격 데이터 (Binance WebSocket, 한국투자증권 API, Yahoo Finance)
  기술적 지표 계산 (RSI, MACD, 볼린저밴드, 거래량)

[신호 생성 레이어]
  각 AI 전략 알고리즘 → 매수/매도/보유 신호 출력
  신호 강도 점수화 (0~100). 임계값(기본 70) 초과 시 실행.

[실행 레이어 — 페이퍼 트레이딩]
  가상 주문 실행: 신호 발생 시점 현재가 기준
  슬리피지 시뮬레이션: 코인 0.1%, 주식 0.3% 적용
  포지션 DB 저장

[알림 발행 레이어]
  트레이딩 이벤트 발생 시 구독자 목록 조회
  Firebase FCM → Web Push 발송 (5초 이내 목표)
  알림 이력 DB 저장

[근거 생성 레이어]
  거래 발생 시 LLM 호출 → 매매 근거 1~2줄 생성
  예: "RSI 28로 과매도 진입, 최근 3일 거래량 평균 대비 2.3배 증가"
```

### AI 성과 지표

- **승률**: 청산된 포지션 중 수익 포지션 비율
- **총 수익률**: 시작 원금 대비 현재 모의 자산 증감
- **CAGR**: 연환산 수익률
- **MDD (Maximum Drawdown)**: 최대 낙폭
- **평균 보유 기간**: AI 성격 파악용

## 11. 리스크 및 법적 고려사항

### 법적 리스크

#### 투자 권유 금지

- AI 트레이더의 매매 행동은 **정보 제공 목적**이며, **투자 권유가 아님**을 명시.
- 자동 실행 없음 → 사용자가 직접 판단하고 직접 실행 → 일임 운용 규제 해당 없음.
- 모든 화면 하단 고정 문구: "본 서비스는 AI 모의투자 정보 제공 서비스입니다. 투자 권유가 아니며, 실제 투자 결과와 다를 수 있습니다. 투자 손실에 대한 책임은 투자자 본인에게 있습니다."

#### 모의투자 명확화

- 앱 내 "모의투자(페이퍼 트레이딩)" 배지 항상 표시.
- 온보딩에서 모의투자 개념 명시적 설명. AI가 실제 돈을 운용한다는 오해 방지.

#### ~~카피트레이딩 자동 실행~~ — 완전 제거

- v2.1부터 자동 실행 기능 없음. 계획에서 영구 제외.
- 이유: 일임 운용 간주 가능성 + 증권사 API 제휴 복잡도 + MVP 집중.
