## Phase 0 — 기반 구축 (MVP) | 2026 Q2

**목표**: 핵심 기능만 갖춘 베타 출시. 사용자 반응 검증.

### 개발 목표
- [ ] 국내 주식 실시간 가격 (코스피/코스닥)
- [ ] 코인 실시간 가격 (업비트 원화마켓 전체)
- [ ] 통합 종목 검색 (주식+코인)
- [ ] 관심종목 즐겨찾기 (최대 50개, 주식+코인 혼합)
- [ ] 종목 상세 페이지 (가격, 일봉 차트, 기본 정보)
- [ ] 주요 뉴스 피드 (관심종목 연관)
- [ ] 시장 지수 (코스피, 코스닥, BTC 도미넌스)
- [ ] 회원가입/로그인 (이메일 + 소셜)

### 인프라 목표
- [ ] AWS 기반 배포 파이프라인
- [ ] 실시간 데이터 파이프라인 (Kafka + WebSocket)
- [ ] 모니터링 (Datadog + Sentry)
- [ ] CI/CD (GitHub Actions)

### 성공 기준

> v2.2 현실화 (PRD 2.2 기준으로 동기화, 2026-03-19)

- 베타 가입자 100명 확보 (D+30)
- AI 트레이더 구독률 50% 이상 (가입자 중 1개 이상 구독)
- 평균 구독 AI 수 1.5개/인 이상
- WAU/MAU 35% 이상
- FCM Web Push 연동 완료 및 알림 정상 발송
- 가격 데이터 지연 3초 이내
- 크리티컬 버그 0건

## Phase 1 — 성장 | 2026 Q3

**목표**: 핵심 지표 개선, 차별화 기능 추가

### 기능 목표
- [ ] 미국 주식 (나스닥 100, S&P 500 주요 종목)
- [ ] 포트폴리오 통합 뷰 (주식+코인 통합 수익률)
- [ ] 가격 알림 (푸시 알림)
- [ ] 테마/섹터 분류 (반도체, AI, 바이오, DeFi 등)
- [ ] 분봉 차트 (1분/5분/15분/1시간)
- [ ] 종목 비교 (최대 3개)
- [ ] 관심종목 그룹 관리

### 기술 개선
- [ ] 앱 성능 최적화 (LCP < 2.0초)
- [ ] 오프라인 지원 (Service Worker, 마지막 가격 캐시)
- [ ] 접근성 개선 (WCAG 2.1 AA)

### 성공 기준
- DAU 1만 명
- D30 리텐션 40%
- 앱 스토어 평점 4.3 이상

**목표**: 프리미엄 구독 출시, 수익 모델 검증

### 기능 목표
- [ ] **프리미엄 구독** (월 9,900원)

  - 실시간 알림 무제한
  - 고급 차트 지표 (MACD, RSI, 볼린저밴드)
  - 포트폴리오 심층 분석
- [ ] 커뮤니티 (종목 토론, 투자 아이디어 공유)

- [ ] 재무제표 요약 (국내 주요 종목)

- [ ] MRR 1,000만원 달성

### 성공 기준
